# ScopeCdnRedirect 1.1.0

Отдельный нативный мод для загрузчика Il2CppNativeKit клиента Ananata_2810.
Подменяет URL запросов UnityWebRequest с точным исходным хостом:

```text
https://l50-media-cn-hangzhou-test.oss-cn-hangzhou.aliyuncs.com/<путь>
→ https://s3.twcstorage.ru/48654ade-be6da43d-250e-487d-bc51-2934b9358586/ananta/scope/<путь>
```

Работает на уровне UnityWebRequest.SetUrl перед установкой адреса. Новый адрес
используется для DNS, TLS и HTTP Host. Сертификат проверяется обычным способом.
Сохраняются путь, escape-последовательности, остальные параметры запроса, метод, тело,
заголовки и обработчики ответа. HTTP исходного домена тоже переводится на HTTPS CDN.
Пути не декодируются и не кодируются повторно. Другие домены не меняются.
Параметр x-oss-process=image/... удаляется из запроса к CDN, поскольку этот
сервер его не поддерживает. Исходный URL в UI остаётся доступным для определения
нужных пропорций. Остальные query и fragment сохраняются.

## Локальные пропорции и кадрирование

LocalImageAspect=1 включает перехват URawImage.OnPopulateMesh/GetDrawingDimensions.
Обрабатываются только картинки исходного хоста или заданного CDN-префикса.
Разбирается всё значение x-oss-process=image/... с поддержкой URL encoding.
Размеры w/h произвольные положительные числа до 65535, а не фиксированные 512/316.
Порядок токенов w/h/m может отличаться. Поддерживается один этап resize.

* resize,m_fill,w_W,h_H — центрированная обрезка через UV под W:H.
* resize,m_lfit / m_mfit / m_pad — вписывание исходника без растягивания.
* Только w или h — сохранение исходных пропорций, без обрезки.
* quality/format/interlace распознаются, но повторного кодирования не выполняют.
* Неизвестные операции, другие gravity, rotate, crop, watermark, m_fixed,
  повторные resize и нестандартные токены не имитируются: UNSUPPORTED_IMAGE_PROCESS
  в логе, изображение остаётся без локальной обработки.

Вся обработка — UV и четыре координаты UI-геометрии при построении mesh.
Новые текстуры, копии пикселей, JPEG/PNG-перекодирование не создаются.
UI-рамка не меняется. Результат вписывается в неё с сохранением пропорций;
если пропорции рамки и W:H отличаются, остаются поля.
Временные UV и флаги возвращаются сразу после построения mesh: состояние не
остаётся на повторно используемых элементах ленты, не хранит ссылки на текстуры
и не требует обхода UI каждый кадр. Оригинальные файлы всё ещё могут занимать
больше памяти, чем серверные миниатюры; мод не уменьшает их разрешение.
Лог LOCAL_IMAGES_READY подтверждает установку UI hooks, LOCAL_IMAGE содержит
режим и распознанные размеры. Первые 100 таких событий записываются в лог.

Настройки в ScopeCdnRedirect.ini: Enabled=1/0, SourceHost, BaseUrl, LogLimit,
LocalImageAspect=1/0 и StripOssImageProcess=1/0 (оба по умолчанию 1).
Для применения настроек нужен перезапуск игры. Лог рядом: ScopeCdnRedirect.log.
READY означает, что установлен hook; REDIRECT показывает исходный и новый адрес.
Значения query в логе скрываются. Кроме удаляемого x-oss-process=image/...,
в реальном запросе они сохраняются.
После LogLimit записей подмена продолжает работать без отдельных записей.

NetworkWhitelist должен разрешать s3.twcstorage.ru через AllowedDomains.
Добавление выполняется при установке с сохранением резервной копии INI.
Если вручную изменить BaseUrl на другой хост, нужно разрешить и этот хост.
Общий домен s3.twcstorage.ru в белом списке разрешает подключения к этому хосту,
а не только к указанному bucket/префиксу.

Мод не запускает прокси и не меняет hosts/DNS или исходные ресурсы клиента.
Это не системный перехват всего трафика: отдельные SDK, которые используют
собственный WinHTTP/WinINet/curl вместо UnityWebRequest, этим hook не охвачены.
Уже созданные до загрузки мода запросы и закешированные изображения не пересоздаются.
Подмена охватывает все методы HTTP через UnityWebRequest, включая POST/PUT;
публичное хранилище CDN само по себе не заменяет серверный API загрузки файлов.

Версия 1.0.1 исправляет NOT_ACTIVE: IL2CPP API missing из версии 1.0.
Урезанное API рефлексии не используется. Перехватывается общий icall движка
UnityEngine.Networking.UnityWebRequest::SetUrl(System.String), который находится
через штатный resolver клиента (RVA 0x398AD10). Его использование подтверждено
в реальном call site RVA 0x200963C7. Строки читаются/создаются через имеющиеся
экспорты mono_string_chars/length/new; сигнатуры проверены по машинному коду.
Проверяется сборка GameAssembly: timestamp 0x6ae10695, SizeOfImage 0x20ad8000.
Поддерживаемый файл при установке: SHA256
461a998f9b6206bd4cd2ef9008b673135e8f24cab74732cadee47394dcfb416f.

Проверка без сети: CTest проверяет точное преобразование примера, host boundaries,
параметры/escape/Unicode, конфигурацию и реальный MinHook-перехват тестового
нативного SetUrl с сохранением аргументов и результата. Дополнительно настоящий
GameAssembly.dll отображается без запуска кода: проверяются экспорты, ABI
строковых функций и вызов resolver из реализации SetUrl. Привязка к runtime и
загрузка изображения из CDN требуют проверки после запуска игры.

Исходники: bin/_server_run/scope-cdn-redirect в рабочем каталоге разработки.
